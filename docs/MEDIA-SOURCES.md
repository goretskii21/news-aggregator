## Правила адаптеров

- Первый успешный снимок — только baseline, без публикаций. Проверка раз в час, ошибки также ограничены часовым повтором.
- SWEET.TV: только JSON-LD ItemList с точным именем и украинским URL подборки; отдельная ссылка на карточку. Исключается страна производства Россия, если она указана в карточке.
- MEGOGO: только украинская витрина (`data-geo=ua`), конкретный виджет подписки, карточки `data-vod-rule=svod`; DTO/TVOD и другие виджеты не используются. Покрытие пока только сериалы.
- Название события формируется по-русски; название произведения сохраняется в языке витрины. В сообщении есть прямой URL, отображаемый общей системой как «Читать далее...».
- Объявление означает новое наблюдаемое добавление в подборку. Не делаем вид, что известен точный момент появления во всём каталоге.
- URL сохраняются в KV между проверками и деплоями; перестановка, исчезновение и возвращение уже известной карточки не дают повторную новость. Новые события доступны очереди 48 часов; общий URL-дедупликатор предотвращает повторный приём.
- Необходима постоянная KV-история. Нет хранилища или изменилась схема/география — нет публикаций. Не делаем предположений по общим анонсам, локализации интерфейса или году выпуска.
- Наличие в одной из подписок не гарантирует включение в конкретный пакет пользователя. Новые сезоны/эпизоды существующей карточки пока не отслеживаются.

Никакие пользовательские cookies, логины стримингов или платные API не используются. Дополнительные запросы активных адаптеров: два публичных HTML-запроса в час при исправной KV-кэш-памяти.

«Что посмотреть» публикует каждое новое подтверждённое добавление отдельно при обнаружении, без ожидания расписания или десяти записей. Отправки проходят общий ограничитель скорости; тема без звука. «Кино» — обычные беззвучные дайджесты. Первый снимок каталогов остаётся без рассылки.
