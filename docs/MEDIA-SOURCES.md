## Правила адаптеров

- Первый успешный снимок — только baseline, без публикаций. Проверка раз в час, ошибки также ограничены часовым повтором.
- SWEET.TV: только JSON-LD ItemList с точным именем и украинским URL подборки; отдельная ссылка на карточку. Исключается страна производства Россия, если она указана в карточке.
- MEGOGO: только украинская витрина (`data-geo=ua`), конкретный виджет подписки, карточки `data-vod-rule=svod`; DTO/TVOD и другие виджеты не используются. Покрытие пока только сериалы.
- Название события формируется по-русски; название произведения сохраняется в языке витрины. В сообщении есть прямой URL, отображаемый общей системой как «Читать далее...».
- Объявление означает новое наблюдаемое добавление в подборку. Не делаем вид, что известен точный момент появления во всём каталоге.
- URL сохраняются в KV между проверками и деплоями; перестановка, исчезновение и возвращение уже известной карточки не дают повторную новость. Новые события доступны очереди 48 часов; общий URL-дедупликатор предотвращает повторный приём.
- Необходима постоянная KV-история. Нет хранилища или изменилась схема/география — нет публикаций. Не делаем предположений по общим анонсам, локализации интерфейса или году выпуска.
- Наличие в одной из подписок не гарантирует включение в конкретный пакет пользователя. Новые сезоны/эпизоды существующей карточки пока не отслеживаются.

Никакие пользовательские cookies, логины стримингов или платные API не используются. Дополнительные запросы активных адаптеров: два публичных HTML-запроса в час при исправной KV-кэш-памяти.

«Что посмотреть» публикует каждое новое подтверждённое добавление отдельно при обнаружении, без ожидания расписания или десяти записей. Отправки проходят общий ограничитель скорости; тема без звука. «Кино» — обычные беззвучные дайджесты. Первый снимок каталогов остаётся без рассылки.

### Дополнительная проверка Киевстар ТВ

Публичная страница [новинок](https://tv.kyivstar.ua/ua/something-new) содержит отдельные секции «Прем’єри на підході!» (будущие релизы) и «Вже на платформі» (доступные карточки с прямыми ссылками). Обычный запрос возвращает оболочку JS-приложения; серверная версия для поискового робота содержит карточки. Само включение в секцию «Вже на платформі» не доказывает включение в подписку. Проверенная карточка вернула Movie JSON-LD без offers и только предложение входа/загрузки условий просмотра. Поэтому автоматическая публикация по этой странице пока не включена.

[Официальное описание email-рассылки](https://kyivstar.ua/news/id200820261400) подтверждает новости премьер и пополнений, но это также рекомендации, акции и розыгрыши. Подписка пользователя на рассылку не оформлялась; доступ к почте не использовался. Официальный Telegram-канал самого Киевстар ТВ не подтверждён.

### Киевстар ТВ: разрешённая пометка условий

По уточнению пользователя подключён адаптер [доступных новинок](https://tv.kyivstar.ua/ua/something-new). У каждой публикации обязательная пометка «Подписка или покупка» — доступность в подписке не утверждается. Парсится только section с data-testid=new-on-ks-tv-available, article с data-testid=available-card; будущие премьеры отбрасываются независимо от указанной даты. Локальная проверка: 6 карточек. Страница отдаёт серверный HTML для User-Agent Googlebot; обычный User-Agent отдаёт JS-оболочку. Это техническая зависимость адаптера: при отсутствии секции публикации блокируются. Первая проверка создаёт тихий baseline, последующие — раз в час, события сразу проходят общую беззвучную очередь. Добавляется один HTML-запрос в час; карточки отдельно не запрашиваются. Изменение сезона при прежнем URL пока не создаёт отдельное событие.

### Prime Video: публичная витрина подписки

[Included with Prime](https://www.primevideo.com/-/ru/storefront/subscription/prime) доступен без входа с Windows: HTTP 200 и украинские recordTerritory/currentTerritory=UA. Регион берётся из RequestContext в JSON страницы, а не из адреса /region/eu/. Пользовательские cookies и сессия Amazon не используются.

Адаптер требует обе территории UA, тип Movie/TV Show/Season, явное предложение доступа к Prime и бейдж новинки (фильм/сериал/сезон, премьера сезона, недавно добавлено). Покупка/аренда без предложения Prime и другие платные каналы исключены. Предложение Prime может сосуществовать с покупкой: доступ по подписке проверяется отдельно.

Первый снимок тихий; затем один запрос в час, отдельные беззвучные публикации новых карточек. С Windows разобраны 6 карточек. Охват ограничен видимыми контейнерами витрины; полное покрытие каталога и новых эпизодов не обещается. При другом регионе Cloudflare публикации блокируются. Календарь Create with Prime Video не используется: найденные регионы не включают UA, а US/UK-премьеры не доказывают доступность в Украине.
